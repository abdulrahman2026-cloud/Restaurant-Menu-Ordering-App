# Interactive Restaurant & Coffee Shop Ordering Web Page

صفحة ويب تفاعلية لمطعم/كافيه تتيح للزبائن تصفح قائمة الطعام والمشروبات، إضافة المنتجات لسلة الشراء، وحساب الإجمالي تلقائياً باستخدام JavaScript.

## المميزات الرئيسية (Features)
- قائمة طعام تفاعلية مقسمة لمنتجات ومشروبات.
- سلة شراء ديناميكية لحساب مجموع الطلبات.
- تصميم تجاوبي متوافق مع كافة الشاشات والموبايل (Responsive Layout).

## التقنيات المستخدمة (Tech Stack)
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Vanilla JS - DOM Manipulation)
